# LICK — Monumental Systems Landing Page

Open `index.html` in a modern browser. All band imagery is local in the `assets/` folder. The Monumental Systems pyramid stage now tries to load Three.js from a CDN for a live rotating mark; if that request is blocked, the built-in CSS pyramid fallback still runs.

## Interactive features

- Mouse-reactive neon plasma field and lightning cursor sparks
- Click-to-cast lightning bolts anywhere on the page
- Hover/click member cards for visible card sparks and voltage bursts
- “Ignite Pyramid” plasma jet blast with screen flash and success reactor meter
- Browser-native WebAudio band loop via **Power On**: distorted guitars, bass, drums, and synth chaos
- Theme mutation: magma, acid, and blood chrome palettes
- 3D tilt poster and member cards
- Live 3D Monumental pyramid stage with CSS fallback
- Storm mode, prophecy generator, and keyboard shortcuts
- Front-end-only email demo; no data is sent or stored

## Keyboard shortcuts

- `L` launches the plasma jet
- `S` toggles storm mode
- `M` mutates the theme
- `P` spins a new prophecy
